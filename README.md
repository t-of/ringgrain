# RINGGRAIN — 毎日の気分が年輪になる

寝る前に今日の気分を 5 色から 1 つ押すと、切り株の断面の一番外に 1 日ぶんの帯が足される。1 か月で 1 周、1 年で 12 本の年輪になり、その年の気分が 1 枚の絵として残る。

## 🔗 リンク

- 遊ぶ: https://t-of.github.io/ringgrain/
- 制作: [T.OF...](https://t-of.github.io/)

## 遊び方

1. 寝る前に、今日の気分の色を 1 つ押す（最高 / いい / ふつう / いまいち / つらい）。もう一度押すと色を変えられる。
2. 押した色で、切り株のいちばん外に 1 日ぶんの帯が足される。1 か月で 1 周、1 年で 12 本の年輪になる。
3. 年輪の帯をタップすると、その日の色を付け直す・消すことができ、その月の色ごとの日数も見られる。
4. 上の「‹ 2026 ›」で前の年の切り株を見られる。「画像で保存」で年輪の画像（1080×1350）を共有・保存できる。

- 1 日の区切りは午前 4 時（0 時〜4 時に押すと前の日の記録になる）。
- 付けなかった日は暗いすき間になる。はじめて記録した日より前は木の地の色。
- 記録はこの端末の中（localStorage）だけにあり、どこにも送らない。設定から書き出し（JSON）・読み込み・すべて消すができる。
- 日本語と英語。端末の言語で決まり、設定の「言葉」で変えられる。

## アプリとして入れる（PWA）

- iPhone / iPad: Safari で開き、共有 → 「ホーム画面に追加」
- Android / PC の Chrome・Edge: 画面の「アプリにする」ボタン、またはアドレスバーのインストールボタン

## 開発

ビルド不要。フォルダをそのまま静的サーバで開く。

```sh
python3 -m http.server 8000   # → http://localhost:8000/
node tools/test.mjs           # 決まりの自己チェック（1 日の区切り・うるう年・書き出しと読み込み）
```

| ファイル | 中身 |
|---|---|
| `logic.js` | 画面に触らない決まり（日付の区切り、記録の形、読み込みの確かめ、タップした所の日）。node からも読める |
| `main.js` | 画面・年輪の描画（Canvas）・音（Web Audio）・言葉の一覧 |
| `tools/test.mjs` | `logic.js` の自己チェック |

### 保存するデータ

| キー | 中身 |
|---|---|
| `ringgrain.days` | `{ v: 1, first: 'YYYY-MM-DD', days: { 'YYYY-MM-DD': 0〜4 } }`（0 = 最高 … 4 = つらい。`first` ははじめて記録した日） |
| `ringgrain.settings` | `{ v: 1, sound, lang: 'auto' / 'ja' / 'en', coached, hinted }` |

形を変えるときは `v` を上げ、`logic.js` の `normalize()` で古い形から引き継ぐ。
書き出しのファイルは `{ app: 'ringgrain', v: 1, exported, first, days }`。
